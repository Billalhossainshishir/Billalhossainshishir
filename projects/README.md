# Project Portfolio

This index brings together my strongest public technical work. I keep assessment instructions, private datasets, client-confidential material, and teammate code out of public repositories where appropriate.

## AI & Machine Learning

### [Star Type Classification with Machine Learning](https://github.com/Billalhossainshishir/star-classification-machine-learning)
Multiclass classification using Decision Tree, Random Forest and SVC, with data-quality review, leakage prevention, stratified 5-fold cross-validation, GridSearchCV and final hold-out evaluation.

### [Machine Learning Model Comparison](https://github.com/Billalhossainshishir/machine-learning-model-comparison)
Binary classification comparing Logistic Regression and Decision Tree models for a fictional heat-safety problem, using accuracy, precision, recall, F1 and confusion matrices.

## Data & Cloud

### [Cloud Data Processing](https://github.com/Billalhossainshishir/cloud-data-processing)
A portfolio-safe version of my transformation-worker contribution to a distributed Nectar Cloud workflow using Python, Flask, pandas and scikit-learn.

## Algorithms & Software Fundamentals

### [Emergency Route Planning](https://github.com/Billalhossainshishir/emergency-route-planning)
C implementation of weighted adjacency-list graphs, Dijkstra's shortest-path algorithm, a binary-heap priority queue, path reconstruction and a 24-test suite.

### [Data Structures Performance](https://github.com/Billalhossainshishir/data-structures-performance)
C implementations using arrays, ordered linked lists, AVL trees and hash tables for a many-to-many database-style problem and performance comparison.

### [UNIX Shell Scripting Utilities](https://github.com/Billalhossainshishir/unix-shell-scripting)
POSIX shell utilities demonstrating file validation, compression benchmarking, UNIX session monitoring, text processing, argument handling and simple persistent storage.

## Industry Project

### [RAMIFY OS — Case Study](ramify-os.md)
University industry project focused on project coordination, requirements, testing, documentation and client feedback for a browser-based AI product-trust demonstration. The case study is public instead of team/client source code.

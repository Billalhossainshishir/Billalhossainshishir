# Emergency Route Planning

## Overview

A C programming project focused on finding efficient emergency routes through a weighted graph.

## Technical approach

- Represented the network using a weighted adjacency-list graph.
- Implemented **Dijkstra's shortest-path algorithm**.
- Used a **binary-heap priority queue** for efficient node selection.
- Reconstructed the final route from predecessor information.
- Added handling for invalid and unreachable cases.

## Testing

I created **24 unit tests** covering:

- Graph operations
- Priority-queue behaviour
- Shortest-path calculations
- Route reconstruction
- Invalid input
- Unreachable destinations

**All 24 tests passed.**

## Technologies

`C` · `Weighted Graphs` · `Dijkstra` · `Binary Heap` · `Unit Testing`

## What I learned

- How graph representations affect algorithm implementation
- How priority queues improve shortest-path search
- How to reconstruct a route from algorithm state
- How structured unit testing improves confidence in algorithmic code

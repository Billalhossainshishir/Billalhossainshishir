# Data Structures Performance Benchmarking

## Overview

A C project exploring different data structures for a database-style food-delivery order system and comparing their search performance.

## Data structures implemented

- Arrays
- Linked lists
- AVL trees
- Hash tables

## Evaluation

I benchmarked search performance across increasing dataset sizes and compared how the structures behaved as the amount of data grew.

In my evaluation, **AVL trees performed best overall** for the tested search workload.

## Technologies

`C` · `Arrays` · `Linked Lists` · `AVL Trees` · `Hash Tables` · `Performance Benchmarking`

## What I learned

- How implementation choice affects lookup performance
- Why balanced trees can be useful for ordered search operations
- How to benchmark data-structure behaviour rather than relying only on theory
- How to compare trade-offs between simplicity, memory use and performance
